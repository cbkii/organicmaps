# InCar UI enhancements and physical qualification

Stacked on PR #78 (`73ddefdac73cf7825a19693869d166aca2a1ffed`). Android 10/API29 remains supported. This work does not qualify the underlying startup/renderer changes on a physical TS18.

## Implementation contract

- The existing ThemeSwitcher/AppCompat coordinator owns Light, Dark, Scheduled and explicit Follow system. Manual choices never write Android's global theme. Framework alerts now inherit the app dialog theme; speed presentation invalidates unchanged-severity colours on effective theme changes. Downloader icon caching distinguishes effective day/night even while the preference stays SYSTEM.
- Full-height speed warning is independently stored in OrganicMapsPrefs, defaults ON even for existing installs with no saved key, and does not affect the existing circle/ribbon warnings. It consumes their evaluated severity and fresh-data authority, with the existing 105/103% orange and 110/108% red hysteresis unchanged. It is passive 50% paint, on the physical driver's side, width current speed circle + 8dp, within system-bar/cutout insets. Loss of valid speed/limit authority, renderer loss, stale/invalid data and the disabled preference hide it. The strip follows the same active warning as the circle even in the regular map. Its separate passive app-owned layer preserves the existing speed readout above map controls. Warning/handedness preference changes repaint immediately.
- InCar preferences are sized during adapter binding; selectable rows (including disabled actions) retain a 76dp minimum, category headings wrap content. Choice dialogs share one AndroidX lifecycle/value/cancellation owner throughout Settings, InCar and Voice Instructions. Content can grow beyond 80dp without changing widths. Non-InCar adapters retain AndroidX defaults.
- Driving Options, Background Tiles, Storage, Map Language and Help use their existing owners with actual row-sized hit bounds. Whole-row switches have one action and one accessibility switch node. Driving Options scrolls in short InCar windows. Map Layer items include labels, retain icon size, and scroll only when preserving the 76dp floor requires it. Saved Places completion dismisses the completed editor; cancellation keeps unfinished edits. Existing bottom-sheet/category menu actions keep their 76dp normal height and expand for translated labels.
- Existing 76dp normal, 69dp compact map-rail and 55dp emergency map-control tiers, dialog fractions, menu widths and route/startup contracts are retained.

UI tests exercise real row measurement/recycling, OS-injected edge taps with exactly one state change, banner geometry/alpha and unchanged-severity theme repaint. Static checks complement these; they do not establish physical hit alignment.
