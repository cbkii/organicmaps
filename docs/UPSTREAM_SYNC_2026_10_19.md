## Selected improvements and adaptations

- Coalesce renderer uploads, discard cancelled-read payloads, and preserve accepted reads through viewport changes. No tracing/scenario camera owner is imported.
- Correct full-width Vulkan callback IDs and swapchain-image presentation semaphore lifetimes. No rendering backend/default is changed.
- Protect routing graph/cache access and alternative choices across rebuilds. Extra fork road/corridor/metadata/speed queries also respect worker ownership and fail open until idle.
- Freeze the existing car avoidance settings per calculation and invalidate incompatible active/alternative caches. Existing persisted keys, JNI and mode selection remain unchanged.
- Repair rectangle clipping and wrapped country routing, clear reused triangle storage, and update only the packed runtime border asset.
- Preserve category identity/metadata on reload without dropping fork compilation/catalogue support or writing synchronised files back.
- Preserve all POI synonyms and readable suggestion labels; fix folder-icon handling and route-list corner clipping.

The packed border binary has the same **1,159 region names in the same order** and
**2,319 container sections** as the retained binary. Container offsets and section
bounds were checked. Size falls from 5,919,042 to 5,642,269 bytes. SHA-256:
`5d7ea7230b395a7f93adecc6b5bbe35e7f95a08809097fb36c45ed83ffa6d3a0`.
Source polygons, generator bulk and maintenance tools are excluded. Country listing
files do not change across either the fork divergence or this upstream range.

shape batching/cancelled tails, all fork router-query guards and cache generation,
request avoidance snapshots, bookmark replacement and geometry intersections.

are retained for the selected changes; Qt/GPU-dependent native suites are **NOT_RUN**
locally because this environment has no CMake/Qt/Android SDK build toolchain.

from the PR's exact-head CI, not inferred from local harnesses. No TESTING/signing or
production release is requested by this sync. PR #69's earlier signed APK validates
its own head only, not these additional fixes.

Physical TS18, renderer performance/memory, Vulkan context recreation, map-boundary
behaviour, route-rebuild interactions, process/reboot/cold boot and ACC remain
**NOT_RUN**. The fork's existing camera/location/viewport/START and approved marker
assets remain unchanged. The global formatter baseline is inherited separately;
